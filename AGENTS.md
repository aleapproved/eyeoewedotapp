# Working agreement

This repository contains the Eye O Ewe static website. The mobile app remains
in the separate app repository.

- Keep the deployable website source under public/.
- Keep the versioned public URLs stable unless the product owner explicitly
  changes them.
- Do not add app source, backend code, credentials, personal data, generated
  build output, or signing material here.
- Run npm test after website changes.
- Deployment is manual and documented in docs/public-pages-deploy.md.
- Confirm the exact Cloudflare Pages project before any production deployment.

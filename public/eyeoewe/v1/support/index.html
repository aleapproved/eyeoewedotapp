Contact support

Use the support contact channel shown in the store listing. Describe what you were trying to do, the app version, and the device platform. Please do not send one-time sign-in codes, invitation codes, session tokens, UUIDs, or real financial records.

Common checks

  • Sign-in needs an internet connection. Check the address carefully and request a new code if the previous one expired or was already used.
  • An existing signed-in session can open cached groups offline. New sign-ins, invitation redemption, leaving, group deletion, and account deletion need an internet connection.
  • Pending changes reconcile when the app returns to the foreground or is opened again. The mobile operating system does not guarantee sync after the app has been terminated.
  • If an owner wants to delete their account, they must first transfer ownership or delete every active group they own.

Data and privacy

Read the version 1.0 privacy policy for the implemented data inventory, export boundary, group lifecycle, and account-deletion behaviour.

Eye O Ewe support does not ask you to disclose a password or a one-time code.
